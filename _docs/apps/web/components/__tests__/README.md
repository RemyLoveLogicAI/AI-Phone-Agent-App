## Overview

This directory holds test modules for individual React components used in the web application. At the root level there are two Jest test files: Dialer.test.js and MessageList.test.js. Each file targets a specific React component (Dialer and MessageList respectively) and contains unit tests that exercise that component's expected behavior.

The structure is flat and focused solely on component-level tests. These tests serve to validate UI component logic and are intended to be executed by the project's Jest test runner. Together, the files in this directory provide automated checks that the Dialer and MessageList components behave as intended, helping prevent regressions as the components evolve. This directory plays the role of the component test suite for the web app's components and complements source code located in sibling component directories.


### File Organization

Files are organized flat at the directory root, with each test file corresponding to a single React component. Naming follows the <Component>.test.js convention to allow Jest to auto-discover tests. This keeps tests coarsely aligned by component without additional nesting.
