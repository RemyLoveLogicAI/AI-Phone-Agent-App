## Overview

This directory contains React component source modules that implement specific UI pieces for the web application: Dialer.js provides a Dialer UI component and imports the useState hook; LiveCallIntelligence.js implements a component that imports useState, useEffect, and useMemo for reactive and memoized logic; MessageList.js implements a message list component. These three root-level files represent discrete UI components intended to be composed by higher-level application code.

In addition to the component modules, there is a __tests__ subdirectory that holds unit tests (Dialer.test.js and MessageList.test.js) written for individual components using Jest. The tests validate behavior of the Dialer and MessageList components. Together, the components and tests provide a focused feature area within the web application's docs: UI component implementations plus targeted unit tests that verify component behavior and lifecycle-related logic.


### File Organization

Files are organized by UI component (feature) at the directory root, with a dedicated __tests__ subdirectory for unit tests. Each root file is a single React component module focusing on a specific UI responsibility (dialer UI, live call intelligence, message list). Tests are separated to keep production code and test code distinct.
