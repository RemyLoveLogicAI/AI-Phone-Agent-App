## Overview

The docs/apps directory serves as the collection point for application-level documentation and related test/configuration assets. At this level there are no root files; instead, the directory organizes subdirectories that each contain the files and configuration necessary to build, test, and document specific applications. This grouping keeps app-specific concerns separate from core libraries and higher-level documentation.

Currently, the only subdirectory is web/, which houses the web application's Jest test configuration and setup as well as grouped React UI component sources and storage-related tests used by the web app. The web/ subtree contains a root-level jest.config.js that builds and exports a Jest configuration tailored for a Next application and subfolders that organize UI components and testing assets. Together, these pieces enable developers to discover testing configuration and UI component sources associated with the web app while keeping app-specific test setup separated from other repository concerns.


### File Organization

This directory uses a hierarchical structure where each application gets its own subdirectory (e.g., web/). There are no files at the docs/apps root; all app-specific configuration, tests, and component sources are contained inside their respective subdirectories to keep concerns isolated and discoverable.
