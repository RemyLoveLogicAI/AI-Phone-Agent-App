## Overview

This directory is the source root for the API surface related to adaptive-tools. At the root level there are currently no standalone files; the functional surface is provided through the voice subdirectory. The voice subdirectory contains the NestJS controller and module definitions that expose and register the voice adaptive-tools subsystem with the application.

The voice subdirectory includes an adaptive-tools controller (adaptive-tools.controller.ts) which implements the controller-layer logic for voice adaptive tools, and a NestJS module definition that wires the voice-related adaptive tool services into the larger application. Together, these components expose the API endpoints and perform module registration so the voice adaptive-tools subsystem is discoverable and loadable by the host NestJS application. This directory therefore serves as the integration point between the adaptive-tools implementation and the API layer in the project.


### File Organization

There are no files at the root of this directory; related API implementation is organized into a feature-specific subdirectory named voice/. The voice/ subdirectory groups controller and module files for the voice adaptive-tools subsystem to keep API surface code scoped by feature and to make registration and routing straightforward.
