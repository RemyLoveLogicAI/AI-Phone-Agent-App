## Overview

This directory holds the service implementation and its corresponding unit test for the AdaptiveToolRegistry feature used by the voice API. At the root there are two TypeScript files: adaptive-tool-registry.service.ts, which is a NestJS-style service file that imports the Injectable decorator from @nestjs/common and implements the runtime behavior for the adaptive tool registry; and adaptive-tool-registry.service.spec.ts, which is a Jest-style spec file containing unit tests that verify the service's behavior.

Together these files represent the service layer for the adaptive tool registry within the voice API: the .ts file provides the injectable service used by other parts of the NestJS application, and the .spec.ts file provides test coverage to ensure correctness. This directory is focused and flat in structure — implementation and its tests are colocated to make it straightforward to update behavior and corresponding tests in tandem. The role this directory plays in the larger system is to encapsulate the logic for the adaptive tool registry and to provide test assurance for that logic within the voice portion of the API codebase.


### File Organization

Files are organized in a flat layout: one service implementation file and one unit test file. The implementation (adaptive-tool-registry.service.ts) is colocated with its Jest-style spec (adaptive-tool-registry.service.spec.ts) to simplify development and testing workflows.
