## Overview

This directory holds the API surface and module registration for the voice adaptive-tools subsystem. At the root it includes a NestJS controller (adaptive-tools.controller.ts) that exposes the voice adaptive tools-related controller logic within the application's API, and a NestJS module definition (voice.module.ts) that declares and wires up providers and controllers for the voice subsystem.

Beneath the root, the services/ subdirectory contains the AdaptiveToolRegistry service implementation and its unit tests used by the voice API to manage adaptive tool registry behavior. Together, the controller, module, and service(s) form a small feature area: the module registers the AdaptiveToolRegistry service and controller so the NestJS application can route voice-related adaptive tool requests to the implemented service logic, and the services/ tests validate that behavior. This directory therefore groups the feature-level controller/module surface and its corresponding service implementation and tests, enabling the voice adaptive tool functionality to be integrated into the larger API.


### File Organization

Files are organized by feature: root-level files expose the module and controller for the voice adaptive-tools feature, while the services/ subdirectory contains the AdaptiveToolRegistry implementation and its unit tests. This keeps the API wiring (module + controller) separate from service implementation and tests.
